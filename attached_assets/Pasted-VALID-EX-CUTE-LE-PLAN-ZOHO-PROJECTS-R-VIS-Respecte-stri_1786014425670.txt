VALIDÉ — EXÉCUTE LE PLAN ZOHO PROJECTS RÉVISÉ.

Respecte strictement ce périmètre :

- Ajouter Zoho Projects dans les paramètres de l’application Système D.
- Réutiliser l’intégration Zoho existante autant que possible.
- Ajouter les scopes Zoho Projects nécessaires.
- Permettre de récupérer / tester les portails Zoho Projects.
- Permettre d’enregistrer le portail sélectionné.
- Créer automatiquement un projet Zoho Projects lorsqu’une soumission passe de “en révision” à “approuvée”.
- Stocker l’identifiant du projet Zoho sur la soumission.
- Prévoir un bouton ou endpoint admin de retry manuel si la création du projet échoue.
- Ne pas créer de tâches Zoho Projects dans ce lot.

==================================================
PRÉCISIONS OBLIGATOIRES
==================================================

1. Déclencheur :
Créer le projet uniquement lors d’une nouvelle transition :
in_review → approved.

Ne crée pas automatiquement de projets pour les soumissions déjà approuvées avant cette implémentation.

Pour les anciennes soumissions approuvées, utiliser uniquement le retry manuel admin si nécessaire.

2. Anti-doublon :
Avant toute création, vérifier si un projet Zoho est déjà associé à la soumission.
Si oui, ne rien recréer.

3. Échec Zoho :
Si Zoho Projects n’est pas configuré, si les scopes manquent ou si l’API échoue :
- l’approbation de la soumission doit continuer ;
- l’erreur doit être loguée ;
- l’admin doit pouvoir relancer la création du projet manuellement.

4. Settings :
La section Zoho Projects doit être ajoutée dans les paramètres de Système D, à côté des autres intégrations.
Elle doit afficher clairement :
- connecté / non connecté ;
- portail sélectionné ;
- test de connexion ;
- message si une reconnexion Zoho est nécessaire.

5. OAuth :
Après ajout des scopes, documente clairement qu’une reconnexion Zoho sera nécessaire pour autoriser Zoho Projects.

6. Hors scope :
Ne crée aucune tâche dans Zoho Projects.
Ne touche pas à Zoho Inventory, Shopify, Stripe, PDF, notifications, produits ou permissions.
Ne crée pas de projet depuis les commandes Système D ou Shopify dans ce lot.
