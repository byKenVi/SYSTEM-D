PRÉCISIONS OBLIGATOIRES
==================================================

1. Notifications cliquables :
- Rends les notifications cliquables uniquement si metadata contient une destination fiable.
- Pour metadata.formId, redirige vers /portal/forms/{formId}.
- Si aucune destination fiable n’existe, garde la notification non cliquable.
- Ne casse pas les actions secondaires comme supprimer une notification.
- Si une carte notification contient un bouton supprimer, empêche le clic de navigation avec stopPropagation.

2. Auto-mark-as-read :
- Marque automatiquement les notifications comme lues seulement après chargement réussi de la page Notifications.
- Ne supprime pas les notifications.
- Garde une distinction visuelle lu / non lu.
- Le badge doit disparaître après marquage comme lu.
- Invalide/refetch unread-count après l’action.

3. Badge mobile :
- Ajoute un indicateur visible sur mobile sans ouvrir la sidebar.
- Réutilise le unread-count existant.
- Ne duplique pas une logique de fetch si un hook ou query existe déjà.

4. Formulaire de soumission :
- Ajoute un bouton “Soumettre” accessible en bas du formulaire.
- Les boutons haut et bas doivent utiliser exactement la même fonction de soumission et le même état isPending.
- Ajoute un scroll vers le premier champ invalide.
- Ajoute ou améliore les messages d’erreur en français.
- Empêche toute double soumission.

5. Page produit Système D :
- Améliore la page sans inventer de données.
- Utilise seulement les données existantes : nom, SKU, prix, stock, description, statut, unité, type produit, disponibilité, image ou placeholder.
- Ajoute les sections :
  - Description ;
  - Spécifications ;
  - Disponibilité.
- Si une donnée est absente, affiche un fallback propre en français.
- Ne rajoute aucun appel direct à Zoho.
- Ne modifie pas les permissions serveur.

6. Dashboard / Boutique :
- Corrige uniquement les libellés confus et les sections clairement vides.
- Ne fais pas de refonte globale.
- Ne masque pas une section si cela risque de cacher une donnée utile en mode admin view-as.
