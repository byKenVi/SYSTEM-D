1. PRODUITS SYSTÈME D — DONNÉES INCORRECTES
==================================================

Problème observé :
Dans l’onglet “Produits Système D”, je vois des éléments comme :
- ENT-006 — Entreposage
- ENT-007 — Entreposage
- ENT-008 — Entreposage
- ENT-010 — Entreposage

Ces éléments ressemblent à des soumissions, services, projets ou commandes opérationnelles, pas à des produits achetables.

Ce n’est pas normal si la boutique Système D doit afficher uniquement des produits catalogue que le client peut acheter.

À analyser :

1. D’où viennent exactement ces éléments ?
   - Zoho Inventory ?
   - soumissions approuvées ?
   - Zoho Sales Order ?
   - Zoho Projects ?
   - produits/services générés automatiquement ?
   - table locale ?
   - autre source ?

2. Pourquoi ces éléments sont classés comme Produits Système D ?
   - absence de client ?
   - absence de cf_client ?
   - mauvais filtre ?
   - service Zoho considéré comme produit ?
   - données opérationnelles synchronisées comme produits catalogue ?

3. Quelle est la définition actuelle d’un produit Système D dans le code ?

4. Quelle devrait être la vraie définition ?
   Je pense que la boutique Système D devrait afficher uniquement :
   - des produits réellement achetables ;
   - actifs ;
   - non assignés à un client ;
   - autorisés à la vente ;
   - pas des soumissions ;
   - pas des services opérationnels ;
   - pas des projets ;
   - pas des commandes ;
   - pas des bons de travail.

5. Comment différencier proprement :
   - produit catalogue ;
   - service opérationnel ;
   - soumission ;
   - commande ;
   - projet Zoho Projects ;
   - bon de travail ?

6. Existe-t-il des champs fiables :
   - product_type ;
   - can_be_sold ;
   - sku ;
   - nom commençant par ENT / LIV / F015 / TRI ;
   - source ;
   - catégorie ;
   - custom fields ;
   - lien avec form_submission ;
   - lien avec Zoho Sales Order ?

7. Propose une correction sûre pour que seuls les vrais produits catalogue apparaissent dans la boutique.

Ne corrige pas encore. Présente d’abord le diagnostic.

4. Pourquoi des pages supplémentaires sont créées ?

   - footer en position incorrecte ;
